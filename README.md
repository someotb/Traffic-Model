# Задача Traffic Model

## Цель

Одна из задач при моделировании сетей — это генерация сетевого трафика. В данном
задании предлагается реализовать несколько моделей сетевого трафика и
проанализировать их характеристики. Далее будем предполагать, что весь трафик
состоит из дискретных пакетов разного размера и разной задержки между собой.

## Технические требования

Проект состоит из частей, написанной на C++ и Python. Программное обеспечение
должно работать под Linux (используйте Ubuntu в WSL, если работаете на Windows). В
качестве итогового артефакта нужно представить архив, в котором будет весь
исходный код проекта (в папках cpp, python), собранный бинарный файл
C++‑проекта, инструкция по воспроизведению работы проекта (без сборки)
на Linux‑системе в формате Markdown.

## Модели трафика

Предлагается реализовать две модели:
- **Равномерная**. Новый пакет отправляется через фиксированный интервал после
предыдущего, и у всех пакетов размер одинаковый.
- **Пуассоновская**. Интервал между новым пакетом и предыдущим имеет
распределение Пуассона, а размер пакета определяется экспоненциальным
распределением.

При желании можно добавить свою модель трафика, но в этом случае просим
приложить её описание в формате Markdown с заданием.

## Требования к C++‑части
- Приложение должно быть консольным.
- Для сборки проекта используйте CMake и компилятор GCC.
- На вход программы, в качестве строки запуска, подаётся путь к файлу. Каждая
модель трафика должна быть представлена в виде отдельного класса.

Файл ввода содержит две строки.
1. **Первая строка** – неотрицательное число с плавающей точкой, равное времени
    симуляции в секундах (не превышает 3600).
2. **Вторая строка**
`<Имя_модели_трафика> <параметр_модели_1> <параметр_модели_2> …`
> Параметры выбираете сами, как и порядок их передачи

_Пример_ : 11. 0 equal: 10 10

Своими примерами файлов приложите к итоговому заданию.

Программа должна сохранять результаты расчётов в формате CSV, где первый
столбец — время прихода пакета, отсчитанное от начала симуляции, а второй
столбец — размер пакета. В качестве разделителя используйте запятую ,.

## Требования к Python‑части

- Приложение (скрипт или Jupyter‑Notebook) отвечает за обработку информации,
полученной из C++‑приложения.
- Приложение читает CSV‑файл, строит графики и вычисляет набор характеристик:
  1. Название модели трафика;
  2. Средний размер пакета;
  3. Средний битрейт;
  4. Средняя задержка между пакетами;
  5. Гистограмма задержек между пакетами;
  6. Гистограмма размеров пакетов.
- Для построения графиков используйте библиотеку **matplotlib**.
- Для работы с CSV используйте любую удобную вам библиотеку.
- При необходимости можно использовать и другие библиотеки, но сведите их
количество к минимуму.

## (Необязательно) Bash‑скрипт

Скрипт должен последовательно запускать C++‑ и Python‑части, чтобы проверить
работу всего задания одной командой. Пример использования:
```
./start_traffic_model - -users_file=/home/ubuntu/users.bin
```
