# Traffic Model

## Структура
### C++
1) В коде представленны два класса(файл `traffic_models.hpp`):
- Poissonian_traffic_model
- Uniform_traffic_model

Для Пуасонновского и Нормального распределений.

2) Файл `common.hpp` для общих структур и функций.
3) `CmakeLists.txt` - для сборки C++ проекта
4) В `main.cpp` создается структура с параметрами запуска и запускается симуляция(которая записывает данные в `data/data.csv`)

### Python
В `main.py` предаставлен код, который рачитывает и визуализирует данные из `data/data.csv`.
Что считает `main.py`:
- Длительность симуляции
- Кол-во отправленых пакетов
- Средний размер пакета
- Средний размер интервала между пакетами
- Средний битрейт

А также выводит два графика:
- Гистрограмма задержек между пакетами
- Гистрограмма размера пакетов

## Запуск

Конфигурация лежит в `data/config.txt`.
Файл состоит из следующих полей:
```
1000.0
poissonian 50 512
```
- `1000.0` - время симуляции в секундах
- `poissonian` - тип распределения(poissonian/uniform),
- `50` - интервал между пакетами(в случае uniform константый, в случае poissonian среднее),
- `512` размер пакета (в случае uniform константый, в случае poissonian среднее)

Бинарник лежит в `cpp/build`, скрипт `run.sh` запускает бинарник из этой папки.
Для Python, рекомендую создать виртуальное окружение и установить зависимости через `requiremets.txt`:

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requiremets.txt
```

Теперь запускаем скрипт `run.sh`:
```
./run.sh
```
